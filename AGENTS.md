Use ASD-STE100 for English explanations and new documentation.

Use black text only. Do not add figure titles. Change these defaults only when
the user explicitly requests coloured text or a title.
After each requested change, render both example figures to PNG, inspect the
images, and show the previews in the reply. Wait for fonts to load before capture.
